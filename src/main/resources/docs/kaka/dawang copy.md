一觉醒来，设计行业变非遗了。最近啊很多博主呢在抖音宣扬，有了image 2我们就不再需要设计师了。因为呢image 2不仅可以生成各种的图，包括但不限于电商的详情页呀、人物的三视图、品牌视觉套图等等，甚至呢还可以生成PSD。等这个技术成熟了，毫不夸张的说，设计生产方式将被彻底的颠覆。那到底是舆论造神还是确有其事呢？今天啊我们就一起来测评一下。第一步呢就随便发送一张你相册里面有的产品图，并且呢让它帮你生成一张宣传的海报。在这边呢我用的就是我昨天吃的巧克力啊，哎呢很快就把海报设计图设计出来了，完全是手拿把掐啊。好，体验一下，不得不说呀image 2的生图能力还是太成熟了。这个海报图呢产品主体呢抓的非常的准，视觉中心很明确，一眼就能让人知道这个是在卖什么。而且啊质感配色呢都做的非常的高级，图片呢很富有层次感。前景呢是巧克力，中景呢有包装，背景呢还有飞溅和悬浮的元素，真的是太牛了。Ok那我们回到主线任务啊，在拿到宣传海报之后呢，给AI来发送这一段的指令，把这张你生成的海报分成若干图片元素，每个元素呢一个单独图像，不要改变对应的位置，这样子呢我可以在PS里面拼合，无需拖动。底色呢为白色，不要伪透明底一个图一个元素，你看它就会把这张海报图呢拆解为不同的元素，一共呢是九张图啊，甚至呢还贴心的提供了这些图的压缩包。那到这一步为止呢，就是没有任何的毛病，图片的元素啊图层呢也是拆分的十分的合理。但是呢它到底能不能智能的生成可以编辑使用的呢？我们来接着发送一下指令，帮我将以上拆分图像拼合成一个文件，去除白色底，不要改变每个元素所在的图层的相对位置，保留每个元素的单独图层。五分钟后啊它真的给我生成了一个PSD的文件，而且啊这个PS呢也是能够正常打开的。那我们来验收一下这个成果。哎，很可惜的是啊，PS呢只是很简单的粗暴的把这个海报从平面的角度分割成了不同的部分。那一个合格的PSD呢应该做到的就是不同产品，不同图层文字是可以编辑的，阴影呢光效单独控制，背景呢是可以替换遮罩和透明通道呢正确，图层命名清晰。但是呢目前阶段的image 2呢确实是可以把一张图片变成PSD啊，但是呢并不能够投入正常的使用。所以啊屏幕前的设计师们真的不用再焦虑了，我是卡卡，关注我一起做AI时代的头号玩家。
