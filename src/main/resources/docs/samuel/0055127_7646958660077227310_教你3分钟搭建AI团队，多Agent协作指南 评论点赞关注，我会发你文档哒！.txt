今天教你三分钟搭建一个agent团队，把各种强大的agent cloud code code x open cloud全拉到扣子里，组成项目组，让他们合作生成这样的电商视频、图片和网站。零门槛有手就会完整操作过程我整理成了文档。那我们为什么需要让AI组成团队呢？你肯定不只有一个AI毕竟每一个AI都各有所长，为了完成一个项目，需要在几个AI之间搬运信息，就好像雇一群员工，但他们互相不认识，看到后面就知道，当他们组成一个团队时候有多爽。首先我们把不同能力的AI牛马一个个创建出来。新建agent有三个不同的选项，通过接入本地agent，在你电脑本地运行这条命令，就能把你的code x cloud code open cloud连上来。比如说给我的code x取名美工，如果你压根没装过cloud code这些产品，你也可以通过新建云端的agent，相当于租一台电脑在云端一键把这些agent产品部署一份。那更小白向的偷懒方案是通过职业模板创建已经调配好的agent。比如这个自媒体运营达人模板，已经带了内容创作、账号诊断、热搜榜等一系列优质的技能。那所有创建好的agent都在这里等着你给他下达指令了。他们每一个都有独立的skills记忆和工作目录，通过对话就能干活，也可以更精细的调教他们，比如设定性格，添加技能。啊，那AI牛马们都创建好了，来新建一个项目。我拉了程序员、美工等agent一起来为我们新产品的电商宣传准备素材。接下来的所有工作都将在这个对话窗口艾特不同的agent一站式完成。顺带一提啊，每一个AI agent还参与了多个项目组，就像真的公司一样。那好啊，开始干活。我们开局只有一张产品图，艾特产品经理，详细写一下产品的需求文档。这时候啊实际上是我们电脑本地的cloud code正在工作，然后艾特美工，让他根据文档做一张产品信息长图，生成的结果相当完美。注意啊我并没有给美工提供太多的信息，他自己就能看到前面的产品需求文档，这就是团队化运作的威力。然后我还想做一条宣传视频，这需要美工和导演的合作，先让美工生成九张分镜图。注意啊这里有一个小技巧，有时候agent互相读不到对方生成的文件，可以让他上传到一个共享的地址，再让导演接力，根据分镜图生成视频。生成视频这种任务等起来还是比较久的。所以我很喜欢一边出门遛弯放松，一边用手机app端下达命令。那刚刚的美工呢其实是code x它调用了GPT image to生成图片。导演呢其实是扣子里的一个agent，他调用了c dance生成视频。这就是我说的发挥团队里每个人的优势。然后我们再用生成好的图片和视频制作成网站，直接艾特开发。我们不需要像以前一样人工搬运这些素材给开发，结果很不错。更有意思的来了，我偶然发现在一个项目里，你竟然不仅可以添加agent，还可以邀请真人。我赶紧邀请了团队里负责做小红书的同事，我同事又把自己养的agent加了进来，而这个负责小红书的同事在睡觉时候，我还能直接艾特他的agent来干活。于是我们两个人五个agent在这里面合作，我们试着生成了一篇小红书的内容。这太native了。未来的团队一定是向我演示的扣子里这种人和agent完美协作的。
