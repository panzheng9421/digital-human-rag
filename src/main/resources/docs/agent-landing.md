# Agent 落地为什么难

智能体产业链现在是"两头热、中间虚"：上游大模型很热，下游应用场景很热，中间真正能把行业知识变成可靠 Agent 的工程化能力极其稀缺。

企业落地 Agent 最大的坑不是模型不够强，而是工程化不到位。常见三个死法：

第一，RAG 幻觉。知识库切得粗、召回不准，Agent 一本正经胡说八道，业务方一次就不信了。

第二，工具调用不稳定。让 Agent 调 API、查数据库，参数拼错、超时、重试风暴，生产环境直接崩。

第三，没有评测。口播 Demo 很香，一到真实流量，准确率、成本、延迟全失控，没法迭代。

架构师做 Agent 的护城河，恰恰是把这三件事工程化：知识切片与召回质量、工具调用的可靠性与幂等、以及一套能持续度量效果的评测闭环。

别再卷"又调通一个模型"，去卷"怎么让它在真实业务里稳定赚钱"。包子没蒸出来，店再漂亮也没用。
