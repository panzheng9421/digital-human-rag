它的工作流，我数给你听：写文案、配音、数字人、剪辑、封面、发布。你看我现在这张脸、这个声音，就是它刚走完"数字人"那步生成的——你只管喂文案，剩下的它全包。老潘后台我偷看过，一条口播，从文案到成片，十来分钟。

弹幕天天有人问：想拍口播，没脸、没时间、不会剪。这东西专治这个 —— 不想露脸？数字人顶上。没时间？它一条龙。一个人一天怼十条口播，不喘气。
