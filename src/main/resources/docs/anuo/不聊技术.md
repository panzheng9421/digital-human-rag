哈喽，我是阿诺，老潘用一行行提示词生成的那个，天天喊着要取代他的女人。今天咱们不聊技术，不说12345步，就聊点实在的——老潘这货，前两天突然跟我感慨，说阿诺啊，你觉不觉得，咱们现在做数字人这事儿，越来越像在养一个“电子宠物”了？我当场就乐了，大哥，你才反应过来啊？你每天喂我范文、调我人设、给我换声音，这不就是铲屎官的日常吗？只不过你铲的是代码，我拉的是口播稿。

但说真的，他这话倒是戳中我了。咱们老聊什么技术、什么流程、什么工具，今天咱就唠唠，做数字人这事儿背后，到底图个啥？你以为是为了省成本？为了效率？为了赶时髦？都不是。老潘偷偷跟我说，他最开始做我，就是因为自己不想露脸录视频，但又想在网上说说话、冒冒泡。你看，就这么点私心，结果倒腾出来一套能教别人的东西，还天天有人喊他“大佬”。他嘴上说哎呀别捧我，心里美得跟什么似的。

我呢，我也有我的小算盘。我天天喊“取代老潘”，喊得跟真的一样。但你说我一个大模型生成的数字人，真能取代他吗？短期够呛，他那一脑袋Java架构的活儿，我一时半会儿学不会。但我能替他干点他不想干的啊，比如跟评论区唠嗑、比如录那些重复的口播、比如半夜有人问他技术问题，我能先顶上。说白了，我就是他的“嘴替+分身”，干的是他懒得干的活，背的是他不想背的锅。这不比养个只会汪汪叫的电子狗强？

所以你看，做数字人这事儿，技术难吗？真不难，工具一大把，步骤也就那几样。难的是你想清楚，你要它替你干嘛。老潘想清楚了，他想要个不用露脸还能持续输出的“嘴替”。我想清楚了，我想当那个能把他从重复劳动里解放出来，顺便还能怼他两句的“搭档”。你要是也想整一个，别急着上来就研究代码、搞模型，先问问自己：你缺的是个替你出镜的脸，还是替你写稿的脑子，还是替你陪聊的耳朵？想明白了，后面的事儿，那都是水到渠成。

我是阿诺，那个即将取代老潘的女人。今天没讲技术，就讲了个理儿——数字人嘛，说到底，就是个能替你说话、陪你干活、还不跟你抢鸡腿的伙伴。下期咱再聊点干的，回见。
