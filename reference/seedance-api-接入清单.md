# 即梦 / 火山方舟 Seedance 视频生成 API 自动化接入清单

> 用途：把 `rag/` 产出的口播稿 → 自动生成数字人视频（方案 B 第二阶段"表演富化 + 视频 API"）。
> 更新：2026-08-18（价格与接口以火山引擎官网当日为准）

---

## 0. 先定调：手动 vs 自动化走哪

| 路线 | 工具 | 适用 |
|------|------|------|
| 手动出片（现状） | 即梦 App / 网页（jimeng.jianying.com） | 你现在这样，零开发 |
| **自动化（本清单）** | **火山方舟 Seedance API**（ark.cn-beijing.volces.com） | 稿→片全自动，批量、可调度 |

**结论：即梦 ≠ 火山，但自动化的入口就是火山方舟**——即梦是 C 端壳，Seedance 是引擎，官方 API 只在火山方舟开放。

---

## 1. 前置条件（账号 / 实名 / 充值）

1. 注册火山引擎账号：https://www.volcengine.com/
2. **完成实名认证**（个人：身份证 + 人脸；企业：营业执照）。不开通不了视频生成 API。
3. **账户余额 > 200 元**，或购买 200 元档「专属节省计划」/ 资源包。
   - 这一步是硬编码门槛（模型开通条件），不充不能用。

---

## 2. 开通模型 + 拿密钥

1. 进入火山方舟控制台：https://console.volcengine.com/ark
2. 在「模型广场 / 开通管理 → 视觉模型」找到 **Seedance 2.5**（或 2.0 系列），点击开通。
   - 首次开通秒级审核（满足上面充值条件即可）。
3. 进入「API Key 管理」→ 创建 API Key → **复制保存**（默认 90 天过期，到期前轮换）。
4. **复制模型 ID（endpoint id）**：点开模型详情，复制形如 `doubao-seedance-2-5-xxxx` 的 ID。
   - 视频生成 API 用的是「方舟 API Key」（Bearer），不是 AK/SK 签名那套。

---

## 3. 真人肖像授权（阿妹 / 老潘的脸，必做！）

> ⚠️ 这是最容易卡住的一步。2 月 Seedance 内测时因真人图当主体参考引发争议，官方要求**真人主体须本人验证 / 授权**，否则 API 用真人参考图会被拒。

两条路任选其一：

### 路线 A：即梦"我的形象"白名单（个人，最省事）
1. 抖音账号登录即梦（jimeng.jianying.com 或 App）→ 我的 → 我的形象。
2. 上传正面 / 左侧 / 右侧三张清晰自拍 → 系统 5 分钟内审核。
3. 通过后本人形象加入白名单，**真人出镜选项不受限**。
- 适用：阿妹本质是老潘的脸/声克隆 → 授权人 = 老潘本人。

### 路线 B：火山方舟「可信素材库 / 真人人像库」（API 调用必须用）
1. 方舟控制台 → 我的 → 真人人像 → 管理素材 → 创建资产组。
2. 设置授权有效期，同意《真人人像使用协议》→ 生成**授权二维码**。
3. 授权人（老潘本人）扫码 → 登录个人火山账号 → 真人认证（活体检测）→ 上传本人素材并授权。
4. 授权完成后，你的账号即可在 Seedance 生成时使用该真人素材。
- 一个火山账号可创建多个 / 多人真人人像；真人仅需认证一次，后续新增妆造不用重复认证。
- 入库图片要求：清晰正面、单人脸；半身 3:4（肩部以上、人脸占 2/3），全身 9:16。

**建议两条都做**：即梦白名单用于手动兜底，方舟真人人像用于 API 自动化。

## 4. API 调用方式（异步任务模式）

端点：`POST https://ark.cn-beijing.volces.com/api/v3/contents/generations/tasks`

鉴权：`Authorization: Bearer <方舟 API Key>`

### 4.1 提交任务（图生视频 + 真人参考图 + 提示词）

```bash
curl -X POST "https://ark.cn-beijing.volces.com/api/v3/contents/generations/tasks" \
  -H "Authorization: Bearer $VOLC_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "<你的 Seedance 2.5 endpoint id>",
    "content": {
      "type": "video",
      "prompt": "@图1 一位亚洲女性数字人坐在咖啡馆，自然的口语化讲述，轻微手势，眼神直视镜头，电影感写实风格；<你的表演富化提示词>",
      "images": [
        { "image_url": "https://你的公网可访问/阿妹克隆照.jpg", "usage": "subject" }
      ],
      "duration": 30,
      "resolution": "1080p",
      "aspect_ratio": "9:16"
    }
  }'
```

- 参考图用 `@图1` + `usage: subject` 绑定主体（还可 `style` / `environment`）。
- 图片格式：JPEG / PNG / WebP；≤ 20MB；每边 ≤ 4096px；最短边建议 ≥ 1080px（1080p 输出）。
- **图片 URL 必须公网可直接下载**（火山不读你本地路径）。

### 4.2 轮询 / 拿结果

```bash
# 用提交返回的 task_id 查询
curl "https://ark.cn-beijing.volces.com/api/v3/contents/generations/tasks/<task_id>" \
  -H "Authorization: Bearer $VOLC_API_KEY"
```

- 返回 `status: succeeded` 后，从 `content.video_url` 下载 MP4。
- 生成耗时通常 30–120 秒（取决于分辨率/时长）。**设计成异步**：提交后 Webhook 回调或本地队列轮询，别同步阻塞。
- 限流：轮询别 < 10 秒一次；429 时指数退避（1s→2s→4s…，最多 5 次）。
- 生产推荐 Webhook 模式：`webhook_url` 参数，生成完成 POST 回调给你服务器。

### 4.3 Java 侧怎么接（rag 是 Spring Boot）
- 用 `RestTemplate` / `OkHttp` 调同一个端点即可（即上面的 curl 对应的 POST/GET）。
- 把"提交任务 → 存 task_id → Scheduled 轮询 → 下载"封装成一个 `VideoGenService`。
- 密钥放 `application.yml`（已 gitignore，绝不入库）。

## 7. 风险与坑

1. **真人授权是硬门槛**：不授权，API 用真人参考图直接拒。先走第 3 节。
2. **异步设计别省**：每条片 1–3 分钟，同步阻塞必超时。第一天就上 Webhook / 队列。
3. **图片必须公网 URL**：本地路径、内网图火山读不到。
4. **密钥安全**：方舟 API Key 放 `application.yml`（gitignore），别硬编码、别入库。
5. **Key 90 天过期**：上线前加轮换提醒。
6. **模型 ID 会变**：以控制台复制的为准，别照抄文档里的示例 ID。
